System Architecture & Technology Stack

Machine Learning Engine

Ensemble Random Forest Regressor trained on 5.9M passenger flow intervals. Incorporates tree variance analysis for confidence estimation and crowd utilization classification.

scikit-learn RandomForest Joblib NumPy

High-Performance Backend

Modular Python Flask REST API coupled with an indexed SQLite pre-aggregated analytics cache, delivering sub-50ms query responses across millions of transit data points.

Python 3.12 Flask SQLite3 Pandas

Transit Route Engine

Custom graph-based pathfinding engine with transfer penalty minimization, interchange station identification, and platform-level floor transit guidance.

Graph Search Interchange Matrix Platform Mapping

Interactive Frontend

Ultra-responsive dark UI crafted with semantic HTML5, modern CSS3 Grid, Vanilla ES6+ JavaScript, Chart.js temporal data visualization, and Leaflet.js GIS mapping.

HTML5 / CSS3 JavaScript ES6+ Chart.js Leaflet.js

Platform Capabilities

AI Passenger Demand Prediction

Forecasts arrivals in 15-minute intervals based on hour, day, weather, holiday status, and special urban events.

Interchange & Platform Guidance

Provides transfer floor levels (Concourse vs Ground), platform numbers, and clear step-by-step passenger guidance at interchange hubs.

Interactive GIS Metro Network

Interactive spatial visualization of 85+ stations with geo-coordinates, station types, line filters, and terminal indicators.

Real-Time Congestion Analytics

Temporal trends, 24-hour peak curve analysis, line ridership share, and geospatial station density heatmaps.

Persistent Prediction History

SQLite-backed log of all generated forecasts with filtering, search, model diagnostics breakdown, and CSV data export.

Smart Departure Time Recommendations

Dynamic trip adjustment advice indicating whether to depart 30 minutes earlier or travel on schedule to avoid heavy rushes.
